## 将来対応候補：画像評価後の初期採用枚数制御

現状:
- AI画像評価は動作している
- ただし神田事務所では `selectedCount=30` となり、候補30枚すべてが初期採用状態になることがある
- UI側では採用写真8枚超の警告と確定制御で担保している

将来改善:
- AI評価結果は全候補に保持する
- 初期 `selected=true` は最大8枚までに制限する
- 残りは `selected=false` の未採用候補として表示する
- AIの `shouldUseInLedger=false` は尊重する
- 類似画像が多い場合は relevanceScore / category / 時刻距離で代表画像を選ぶ

狙い:
- レビュー画面を最初から8枚以内で開始できる
- 人間は必要に応じて未採用候補から入れ替えるだけでよくなる
- AIが安全側に倒して全候補を採用推奨するケースでもUIが破綻しにくい
